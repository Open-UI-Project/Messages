## 📱 About the Project

**Open UI Messages** is a modern, open-source SMS application built with Kotlin and Jetpack Compose. Its design is inspired by the ergonomic visual identity of **One UI 8.5**, offering a clean, user-friendly interface optimized for comfortable one-handed use.

This app is a proud member of the **Open UI Project** initiative, dedicated to providing open, telemetry-free, and customizable alternatives to default mobile software.

---

## 🔒 Privacy & Openness First

- **Zero Telemetry**: We do not collect, store, track, or transmit any user data, messages, contacts, or analytics.
- **No Data Selling**: Your personal messages and contacts stay strictly on your device.
- **100% Open Source**: Every single line of application code is open and transparent.
- **F-Droid Ready**: Clean build setup without hidden proprietary trackers or third-party ad networks.

---

## 🛠️ Building from Source

You can build the release APK using standard Gradle commands:

```bash
# Using the Gradle wrapper
./gradlew assembleRelease

# Or using system Gradle
gradle :app:assembleRelease
```

The compiled APK will be generated at `app/build/outputs/apk/release/`.

## ✨ Features

- 💬 **Clean SMS & MMS Experience**: Smooth conversations, thread navigation, and quick replies.
- 📁 **Custom Groups**: Organize conversations into personal, work, or custom categories.
- 📇 **Contacts Integration**: Seamless access to phonebook contacts with fast search.
- 🎨 **One UI 8.5 Design System**: Fluid dark/light themes, rounded corners, and clear visual hierarchy.
- 🔍 **Fast Search**: Instant message and contact searching.
